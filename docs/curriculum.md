# 光集 互动课 · 课程大纲

目标：让完全没有摄影基础的人，用自己的照片，在几分钟一课的互动动画里搞懂「拍」和「修」的基本原理。

## 教学方法（每一课都遵循）

1. **一个值得回答的问题**：用用户自己的话提出，例如「为什么 ƒ/4 比 ƒ/2.8 的光圈小？」。
2. **把原理画出来**：用动画展示机制（像素→直方图、开口大小→进光量），不靠堆文字。
3. **在自己的照片上动手**：每个演示都用打开的照片和应用真实的渲染管线，拖动即看到结果。
4. **回头检验**：一道小题；能用照片本身出题的就用照片出题（例如「这张照片大部分在哪个区域？」）。

统一词汇：五个亮度区「最暗部 · 暗部 · 中间调 · 亮部 · 最亮部」贯穿直方图、滑块提示、曲线和课程。

参考：张小样的抖音视频（6 条，仅作方法参考，内容与画面均为原创，不复制他的脚本或图形）。

## 下一步怎么一起做

1. 你决定下一批的顺序（我的建议：白平衡与色温 → HSL → 焦距 → 帧率与快门 → Log 与 LUT）。
2. 每课先写一句「要回答的问题」和一个「拖什么、看什么」的互动想法；文字我来写成 2–4 步，你看是否通俗。
3. 新课需要的场景写在 `Sources/MediaWorkbenchApp/LessonScenes.swift`，内容在 `Sources/MediaCore/Lessons.swift`，测试会检查每课题目和场景是否完整。
