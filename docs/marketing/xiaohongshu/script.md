# 小红书：视频 + 图文发布包

做一条约 50 秒的竖屏视频：画面和字幕我已经做好（`video.html`），**你只需要录自己的声音，再按需换上自己的真实录屏**。

## 1. 怎么做出成片（约 30 分钟）

1. **渲染画面**（约 5 分钟，需要 Chrome 和 ffmpeg）：
   ```sh
   bash scripts/render-xiaohongshu-video.sh
   ```
   得到 `dist/xiaohongshu.mp4`：1080×1920、30 帧、没有声音。想先看某一秒长什么样：`bash scripts/render-xiaohongshu-video.sh still 12 25`，图在 `dist/xhs-stills/`。
2. **录口播**：照下面的口播稿，用手机「语音备忘录」或电脑的 QuickTime 录。安静的房间、嘴离麦克风一拳、念得比平时慢一点。可以一段一段录，方便重来。
3. **剪辑**（剪映 / 必剪 / iMovie 都行）：导入 `xiaohongshu.mp4` 和你的口播，把每一段口播对到下面表里的时间。口播比画面短一点没关系，比画面长就把那一段的口播删减几个字。字幕直接用剪映「识别字幕」。
4. **（推荐）换上真实录屏**：见第 3 节。
5. 加背景音乐：**只用剪映 / 小红书自带的可商用曲库**，不要用来路不明的歌（会被限流或下架）。音量压到口播的 1/4 左右。
6. 导出 1080P 竖屏，封面用 `dist/xhs-stills/` 里挑一张（建议开场那一帧）。

想改画面：编辑 `video.html`，每个场景的时长在 `data-dur`，文字就在页面里。在 Chrome 里打开可以预览：空格播放，← → 切换场景。

## 2. 口播稿（按场景对时间）

中文口播大约每秒 4–5 个字，每段字数已经按这个控制。

| 时间 | 场景 | 屏幕上的字 | 口播 |
|---|---|---|---|
| 0:00–0:04 | 开场 | DJI 拍完，想在 Mac 上调色？/ DJI Mimo 只有手机版 | **DJI 拍完，想在 Mac 上调色？Mimo 只有手机版。** |
| 0:04–0:09 | 问题 | 专业软件对新手太重了 / 第一眼就是几十个看不懂的滑块 | **Lightroom、PS 又太重，第一眼就是几十个滑块。** |
| 0:09–0:13 | 光集 | 光集 / 简单得像手机 App 的 Mac 调色工具 | **所以我做了光集，Mac 上的简单调色工具。** |
| 0:13–0:22 | 自动 | 点一下「自动」/ 按 A 一键调好，不满意 ⌘Z 撤销 | **点一下「自动」，它先看这张照片，再替你调好明暗和颜色。不会把夜景调亮，不满意随时撤销。** |
| 0:22–0:29 | 预设 | 预设，直接用你的照片预览 | **预设直接用你的照片预览，喜欢哪个点哪个，调好的样子还能存成自己的预设。** |
| 0:29–0:36 | 裁剪 | 裁剪，直接在照片上拖 | **裁剪也一样，直接在照片上拖，拖四个角缩放，比例自动保持。** |
| 0:36–0:43 | 存进「照片」 | 调完，存进「照片」/ 同步到你的 iPhone | **调完直接存进「照片」，同步到 iPhone，视频还能做成 Live Photo。** |
| 0:43–0:49 | 结尾 | 原片不会被改，也不上传任何东西 / 早期版本 / 想试试？评论区告诉我 | **原片不会被改，也不上传。早期版本，想试试的评论区告诉我。** |

小技巧：第一句话决定别人划不划走，所以开场那句**不要慢热**，直接抛问题。

## 3. 换成你自己的真实录屏（让视频更可信）

截图加动效能讲清楚，但**真实的操作录屏更有说服力**。你想换哪一段，就录哪一段：

| 想换的场景 | 录什么 |
|---|---|
| 自动 | 打开一张偏灰的照片 → 按 A → 按 `\` 来回对比前后 |
| 预设 | 在预设缩略图上依次点几个，看画面变化 |
| 裁剪 | 切到「构图」→ 在画面上拖动裁剪框、拖角缩放 |
| 存进「照片」 | 导出 → 保存到「照片」→ 切到「照片」App 里看到结果 → 拿出 iPhone 看同步过去的照片 |

录屏方法：Mac 上按 ⇧⌘5 →「录制所选部分」，框住光集窗口，不要把桌面上无关的东西录进去。放大一点录，手机上才看得清。每段录 8–10 秒就够。

**两种用法**：

- **在剪映里叠**：把录屏放在对应场景的时间段，盖住截图（最简单）。
- **在 `video.html` 里换**：把录屏文件放到 `docs/marketing/xiaohongshu/clips/`，改 `video.html` 顶部 `FOOTAGE`，例如 `auto: "clips/auto.mov"`。再用上面的渲染命令。（渲染时视频素材可能不会逐帧精确，换了录屏建议直接在剪映里剪。）

另外，**你自己的 DJI 画面**（飞行、风景）放在开场前 1–2 秒，会比纯文字开头抓人得多。

### 正文

> 用 DJI 拍了素材，想调一下颜色，才发现 DJI Mimo 只有手机版。想在大屏幕上调，只能回手机上。
> Lightroom、PS 当然什么都能做，但打开第一眼就是几十个看不懂的滑块。
>
> 所以我做了「光集」，一个 Mac 上的调色工具：
> 🔹 点一下「自动」，先得到一张看得过去的
> 🔹 只有 6 个滑块：亮度、对比度、亮部、暗部、冷暖、鲜艳度
> 🔹 预设直接用你的照片预览
> 🔹 裁剪直接在照片上拖
> 🔹 调完存进「照片」，iPhone 上就能看到，视频还能做成 Live Photo
> 🔹 想深入，再展开示波器、色轮、曲线
>
> 原片不会被改，也不上传任何东西。
> 现在是早期版本：Apple 芯片的 Mac、macOS 15 以上，界面目前只有中文。
>
> 想试试的评论区告诉我，也欢迎告诉我哪里不顺手 🙏
>
> （光集是我独立做的软件，和 DJI 官方没有关系。）

## 5. 发之前先过一遍

- [ ] **亲手测一次「存进『照片』」**：导出一张照片、一段视频、一个 Live Photo，确认出现在「照片」里，iPhone 上也同步到了。视频里讲了这一步，必须是真的。
- [ ] 视频里用的照片、DJI 素材都是你自己拍的、你有权公开。
- [ ] 网站和下载链接是通的（见 `docs/marketing/launch-kit.md` 的发布前清单）；GitHub 在国内有时打不开，可以考虑把安装包同时放一份国内能访问的网盘，在评论里说明。
- [ ] 小红书对站外链接和导流有限制，规则会变，**以发布当时平台的规则为准**；链接放主页简介或评论区通常更稳妥。
- [ ] 不要在视频和文案里说价格、「免费」「收费」；不要暗示和 DJI 有合作。
- [ ] 前 1 小时守在评论区回复，互动会影响推荐。
