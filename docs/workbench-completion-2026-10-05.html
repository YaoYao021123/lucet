本轮新增

功能现在的行为范围与边界
光线曝光、鲜明度、高光、阴影、亮度、对比度、白色色阶、黑点。曝光以 EV 表示；其余为应用自己的相对参数。
色彩暖色、色调、饱和度、自然饱和度。暖色是相对调整，不是相机白平衡的 Kelvin。自然饱和度优先影响较低饱和区域，没有肤色识别。
细节清晰度、锐度、降噪、暗角。清晰度使用较大半径局部对比，锐度使用较小半径；降噪是单帧空间滤镜，不是视频时间降噪。
统一效果基础调色先于创意 LUT；预览、PNG、MOV、Live 视频及封面共用参数。各分组可复位。参数借鉴苹果照片和 Lightroom 的组织方式，算法由本应用实现，数值不与两者互换。
直方图RGB 三通道；图片编辑结果与视频当前帧可更新，计算采用缩小样本与延迟合并。明确标注 SDR 显示统计，不用它判断 RAW 或 HDR 的拍摄高光溢出；视频播放中不逐帧计算。
构图90°旋转、镜像、原画幅 / 方形 / 常见横竖画幅、裁切缩放与横纵位置，保留原有手动拉直。中心比例裁切和位置滑块；自由拖四边的裁切覆盖层、透视校正与视频稳像后续实现。

保存、撤销和多选，形成可反复调整的流程

原设计缺口本轮补齐具体约束
撤销 / 重做工具栏与 ⌘Z / ⇧⌘Z。一次连续拖动合并为一步，分组复位也能撤销。当前素材的内存历史最多 100 步；重启恢复配方，不恢复逐步撤销栈。
草稿恢复停手后延迟 350 ms 原子保存 JSON 配方；切换素材、退出时保存，⌘S 可主动保存。应用支持目录 Guangji；匹配原件路径、大小、修改时间，以及 Live 动态资源，原件变化时拒绝旧配方。不是内容哈希去重。
参数版本命名快照、恢复快照；恢复本身可撤销。界面显示最近 50 个版本。记录参数及 LUT 引用，不复制原视频，不使用 Git；所有快照文件保留。LUT 缓存按内容 SHA-256 保存并检查。
混合选择多文件与文件夹加入列表、路径去重、逐项选择、全选 / 清空、收藏与收藏筛选。收藏与路径列表重启保留；文件夹单次最多 5000 项。当前是列表，未实现完整缩略图网格与百万素材索引。
同步调色从当前素材复制选定的光线 / 色彩 / 细节与 LUT 到其他所选素材，修改它们的配方。保留各自的裁切、片段、封面、速度、HDR、音轨。不会自动烘焙成品。当前会话可撤回最近一次同步，后来又改动的素材不会被覆盖。
批量成品所选图片另存 PNG，视频另存 MOV，配对 Live 重制；也可单独批量制作有效 Live 范围。逐项导出降低资源峰值；新建唯一结果目录，生成逐项成功 / 失败原因记录。Live 输出需 0.5–3 秒，无有效范围的条目跳过。
拼图 Live选 1–3 个视频或配对 Live，每格继承保存的调色和裁切，可选起点、速度与上下顺序。静音 SDR，统一 3 秒。等宽上下布局；窗口显示各格中间帧。双拼 1080×1216，三拼 1080×1824。实时合成预览、自由布局、HDR 拼图、独立音轨和拼图项目保存仍待接入。

实际使用顺序

加入素材并调出一个参考效果

打开多文件或加入文件夹，选择当前素材，先调整光线与白平衡，再添加输入空间正确的创意 LUT。原片对比与 i 说明帮助理解调整。

保存一个可返回的参数版本

配方自动保存；尝试第二种风格前，用“快照”保存第一种。出错用撤销，换风格用快照恢复。

同步到所选素材

勾选图片、视频或 Live，打开“同步调色…”，选择复制哪些分组。每段视频继续保留自己的片段和声音。

制作 Live 或导出副本

视频设置范围、封面与速度，确认输出长度。已有 6 秒范围可用 2 倍速输出 3 秒。按需静音 / BGM，最后另存或批量导出。
